# Invitation music

Current track: `nadaswaram-bgm.mp3`

Royalty-free Pixabay instrumental — *Raga Valachi Nadaswaram* by Saseendran
(Pixabay Content License). Nadaswaram is the traditional mangala isai of a
Tamil Hindu wedding.

To use your own song instead, drop an `.mp3` here and set `wedding.audio.src`
in `src/data/wedding.js`.
